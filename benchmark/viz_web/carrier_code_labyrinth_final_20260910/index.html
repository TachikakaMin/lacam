这里的 DIG 是“把被挡住的目标货架挖到 storage block 边缘”；lease 是 Carrier 暂时接管的一小块资源；commitment 是普通机器人已经获批、不能随意改变的未来路线；epoch 是一次从接管到交还的 Carrier 执行周期。

一般并发是怎样保证安全的

Carrier 不再暂停整个仓库，只持有当前 block 的 lease。普通 Pick/Stow 已占用的落地货架会成为 fixed-upper obstacle；非参与机器人的已批准路线会成为带时间的 commitment。每个 Carrier timestep 发动作之前，系统都会重新捕获普通交通的剩余路线并与原承诺后缀比较。如果普通路线发生变化，当前 epoch 会在动作发出前中止并回到待重规划状态。

专门的并发回归使用两条相邻通道：ordinary drive 通过真实 MorePath → VertexUpdate → SpaceRelease 事件链穿过同一个 lease；Carrier drive 同时在另一条通道完成 MOVE → LIFT → MOVE → DROP。两条链最终都完成，且每拍 commitment suffix 校验没有误报。
