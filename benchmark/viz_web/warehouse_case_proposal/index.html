术语说明

Planner assignment：Planner 实跑最终为每件货选择的终点。 eligible goal：某件货允许作为最终位置的全部格子；storage cell 是允许货架落下的货架位；通道只能让载货机器人经过。intra：起点和终点位于同一个货架区；adjacent：终点位于相邻货架区；remote：至少跨越两个货架区；内层 goal：目标格不在 block 边缘。

可解性保障

4 个原有样例和 432 个随机 testcase 都已确认理论可解；后台可解性证书已由 validator 验证，不是 Planner 输出，也不会在本页播放，也不会作为 solver 输入。随机 testcase 不会根据 Planner 成功率、makespan 或 SOC 筛选 seed。

432 个随机配对 testcase

每个地图族都完整覆盖 3 个密度 × 4 个 Agent 数，并分别覆盖 local、mixed、cross-heavy 三种任务分布及单 goal、共享 goal pool 两种模式。Block 密度使用“每块货架数 / block cell 数”的实际值。

密度对照：低、中、高密度使用嵌套货架布局；低密度货架是中密度的子集，中密度又是高密度的子集。新增的只会是随机匿名货架，target 起点和 goal 不变。

Agent 数量对照：Agent 起点使用嵌套前缀；较少 Agent 的起点列表严格是较多 Agent 起点列表的前缀。

配对随机：同一配对组保持 target 起点、goal 定义和随机基准不变，只交叉改变密度和 Agent 数。不会根据 Planner 成功率、makespan 或 SOC 筛选 seed。
