1. Dependency 做什么？

对每个候选 goal 找出当前真正 ready 的叶子任务，并进入这个 goal 的执行代价。

2. τ 和 ρ 做什么？

只告诉 PIBT 哪个 goal、哪个 task 先试；下一物理节点会重新计算。

3. LaCAM 做什么？

首选动作走坏时，在同一个物理节点增加 local constraint，继续枚举其他合法 successor。

因此当前项目不需要再造 Goal-LaCAM 或 Task-LaCAM：应当在每个物理节点，对所有 `(target, goal)` 编译 dependency-aware cost，动态求 `τguide(X)` 和 `ρ(X)`；它们都是同一棵 Carrier-LaCAM 的 guide。只有 Lift/carry/drop 形成的物理 custody 才是硬承诺。
