# 辅助脚手架设计经验（参数化实验结论）

实验装置：`plan_column.py --exp`，塔 F×F×H / 墙 W×H，K 个梯子（方位/形状可调），
N agents，60 秒预算制（`MAX_WALL_SEC`），全部并行跑。

## 经验法则
R1 结构自升（最重要）：locomotive 共升规则下，任何 ≥2 格厚的柱群/墙都能
   "踩着自己长高"，不需要工作面脚手架。脚手架只剩一个职责——**送料通道**
   （每块料都要重新登顶）。金门大桥两面 592 块的施工墙据此替换为 4 条直梯
   （480 块）+ 缆索悬挂安装，T 8505→5276。
R2 悬挂安装：下降的悬浮链（主缆）可以从鞍座逐格向下吊出（站在上一格 z+1
   悬浮块上挂下一格），零脚手架。要求轮廓每步 Δz=1、从两端对称下垂。
   上升链（tommy 的剑）不适用，仍需贴身梯。
R3 梯子数量 K：单塔/单墙 K=1 几乎总是最优——梯子成本 sum(1..H)≈H²/2 是
   平方级，而顶部工作面吞吐是常数；只有 N≥16 且结构有多个独立工作面时
   多梯子才回本。梯子必须分散在不同侧（同侧相邻梯互锁）。
R4 agent 数 N：N* ≈ 5×(独立工作面数)。塔类场景 N*≈12；金门大桥（两岸
   双塔双缆多前沿）N*=24（吞吐 1.55 vs N16 的 1.04）；horse/colonnade
   N*=20；temple N*=16。超过 N* 拥堵反噬（horse N24 比 N20 慢 8%）。
R5 高塔送料成本下界：送料梯 sum(3..H) 不可避免，重设计短墙不赚
   （tommy 实测持平，回退）。降 T 应优先砍"工作面墙"，保留"送料梯"。

## 应用结果（validate 全 PASS）
goldengate 8505→5276 (-38%)  拆墙+悬挂缆+N24
colonnade  1807→1254 (-31%)  N=20
horse      1993→1461 (-27%)  N=20
temple     1124→ 881 (-22%)  N=16
tommy       3210 持平        送料梯已是下界

## R6 落脚点与黏性的交互（往复消除）
观察：goldengate 64% 的移动发生在梯子行，折返率 23.7%——梯子既是唯一
干道又是工作面，agent 反复换向没有净进展。
实验拆分（GG 全量对照）：
  仅强黏性(12)          T=6204 rev%=25.7  (更糟：换不动道，硬顶)
  仅密平台口袋(flat/2)   T=5394 rev%=13.9  (小赚)
  两者组合              T=4864 rev%= 9.4  (-8% T，折返减半)
结论：**落脚点让强黏性变安全**——有了同高错身平台，坚持原目标的 agent
可以让行而不必被重分配；没有平台时强黏性反而加剧顶牛。
适用判据（自动）：长走廊(≥SCAFFOLD_MIN) 且 N≥12 → flat 口袋每 2 格 +
黏性 12；否则稀疏 step 口袋每 8 格 + 黏性 6（tommy 实测密口袋 -12%）。
落脚点模式：flat（同高平台）优于 step（低一格），错身不需要爬高。

## R7 内部柱与尖顶的贴身梯（乐高整砖模式）
两类静态规划器搭不了普通外部梯子的砖：
- **被悬浮层包住的内部柱**（钢琴琴腿，四周都是 z≥4 的琴盖足迹）：
  在"现在还是空地、首块覆盖砖层数 > 梯高"的足迹格子里搭**临时梯**
  （TEMP_STAIR），整条梯（含足迹外的尾巴）在服务柱到顶后立即提前
  拆除（绕过 removal_latch），随后琴盖砖照常盖上。孤岛检查只统计
  还有拆除任务的脚手架格，避免已被结构覆盖的格子误报不可达。
- **完工体上的尖顶**（吉他琴颈，唯一站位放完就困住 agent）：允许
  在已完工结构柱顶上加脚手架（OVER_STAIR，梯高 > 柱终高），随大部
  队最后统一拆。
配套：当没有任何可放砖而有可拆临时梯时，驮砖 agent 把砖退回料仓，
腾出人手去拆（否则全员抱砖围观，梯子永远拆不掉）。
钢琴 T=4005 / 吉他 T=6608 / 椅子 T=16791，validate 全 PASS。

## R8 拆除并行与送料布局（乐高整砖模式，T 大幅下降）
chair 16791→7526 / guitar 6608→4961 / piano 4005→2687 / car 1009→748，全 PASS。
四个叠加改动：
1. **料仓/出生点摊开**：原来 DEPOT 挤在东边北角，南侧脚手架每块料多走
   ~30 格，拆除变成先拆北再拆南的串行(北 75-100/400步 时南=0)。把料仓和
   出生点均匀铺满整条东边后南北同时开拆。
2. **梯子矮一层**：顶层砖 L 站在 L-1 就能放，外部送料梯 hmax→hmax-1，
   直接省掉每条梯最长的那根柱（放+拆双份动作）。TEMP 梯不适用
   （拆除触发条件绑在服务柱到 cap）。
3. **放砖被拆除卡住时停止取料**：ready_pl 空且 ready_rm 非空时 pick_quota
   =0，否则空闲 agent 在料仓边 取料/退料 死循环，没人走去拆临时梯
   （piano 曾因此 5000+ 轮原地踏步）。
4. **N=16 + 密口袋**：N≥12 触发 R6 flat 口袋每 2 格，chair 建造吞吐
   0.632→1.152；口袋多 200+ 块但总 T 仍 -55%。
注：悬空块不能向上搭"之字悬空梯"——侧粘只能同层水平延伸、悬挂只能自上
向下（R2），+1 爬升必须靠堆叠；能利用悬空的地方是把梯子截短和让结构
自升（R1），不是把梯身悬空。
