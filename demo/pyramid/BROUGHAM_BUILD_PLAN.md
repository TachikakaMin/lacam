# MOC-194603 维多利亚马车搭建计划

来源：`/home/yimint/research/dd-lacam/MOC-194603_brickbicycle_brougham.pdf`
（51 页，48 个装配步骤，最后两页为零件清单）。

## 规划映射

1. **车厢底盘与后舱基座（PDF 1–12）**：先铺后舱和驾驶台底板，再建立后舱下部实体层。这样底盘本身就是稳定工作面，不需要一开始搭高脚手架。
2. **驾驶台、前箱和座椅（13–27、36–38）**：两侧低墙、前箱和红色座椅并行施工；车辕连接板在地面独立完成。
3. **后舱窗框与玻璃（5–16、39–40）**：四周逐层闭合。透明窗在模拟器中使用浅蓝整砖表示，黑色角柱承担连续支撑。
4. **车轴、四轮与双车辕（28–35）**：高度场无法表达竖直轮和细长杆，因此它们绑定到底盘锚点；机器人完成锚点放置后，相应总成出现。
5. **上框、弧顶和灯具（41–47）**：黑色顶框完成后封顶；左右灯绑定到顶框前角。规划器会按需要自动合成临时送料梯，并在全部结构完成后拆除。
6. **马匹与最终合装（48）**：白色连接砖是马匹锚点，马和挽具随该任务完成；双车辕延伸到马匹两侧。

## 可执行产物

- 结构输入：`brick_brougham.txt`
- 生成命令：

  ```bash
  BRICK_FILE=brick_brougham.txt \
  BRICK_NAME='维多利亚马车' \
  N_AGENTS=12 \
  python3 plan_column.py --brick --out-prefix plan_brougham
  ```

- 独立验证：

  ```bash
  python3 validate_plan.py plan_brougham.json
  ```

- 播放器：直接打开 `brougham.html`，无需启动 HTTP 服务。

当前已生成并验证的结果：12 台机器人，`T=1282`；49 个车体整砖任务，
29 个按 PDF 步骤绑定的异形构件，39 块临时脚手架；施工带包含

PDF 第 48 步对应的最终状态。

## 表达范围

机器人规划和验证覆盖取料、移动、整砖放置、锚点放置、脚手架搭拆、退料及最终高度。PDF 中的 LEGO 专用异形件（轮、车辕、灯和马）保留外形并绑定真实施工事件，但不参与二维高度场碰撞；这是当前 LaCAM-TAPF 地形模型与实体 LEGO 说明书之间的明确接口。
