# Paper Library README

这是 CORAL LaCAM throughput 任务的论文库入口。检索必须按渐进式披露进行：

1. 先读本 README，用一句话简介筛选候选论文。
2. 再打开对应 `briefs/*.md` 简介页，确认该论文是否能支撑当前 idea。
3. 只有需要章节、算法、设计模式或实验观察细节时，才打开简介页链接的原论文 HTML/PDF。

硬性规则：所有 throughput idea、候选假设、pivot 方向和非平凡实现任务都必须来自本论文库；记录时必须引用至少一个 `briefs/*.md` 简介页，并在需要时引用原论文中的具体锚点。

当前可用本地论文/资料：76 篇。完整下载元数据见 [index.md](index.md)，未解析来源见 [unresolved.md](unresolved.md)。

## Idea 分类路由

在打开具体 brief 前，先用 [idea_categories.md](idea_categories.md) 给候选 idea 选一个主类别，并在实验 note 与 `coral eval -m` 中记录：

- **Map / guidance-graph / weight optimization**：论文主要提供地图、通道、边方向、边权、区域压力、拥堵或任务分配权重方向。只能转化为通用算法代价，不能修改固定 benchmark map/task/seed。
- **Algorithm design**：论文主要提供求解器机制，例如 LaCAM 配置生成、目标-路径耦合、PIBT/优先级继承、局部修复、窗口化、commitment 或实时预算控制。
- **Heuristic function design**：论文主要提供 move ordering、tie-breaker、lower bound、local guidance、冲突估计、候选排序或学习启发式的可实现代理。

当前已确认 real 提升来自 **heuristic function design**，主要对应 [2605.16855](briefs/2605.16855.md) 的 local guidance / hindrance avoidance 思路；详表见 [idea_categories.md](idea_categories.md#observed-paper-grounded-results-so-far)。

## arcs-group

- [2103.08835 - Multi-Robot Routing with Time Windows: A Column Generation Approach](briefs/2103.08835.md)：将仓库多机器人拣选建模为带时间窗、容量和避碰约束的加权集合打包，列生成只生成有价值的机器人路线，并把定价化为 ERCSPP。实验报告完整 CG 相比改造的 CG+MAPF 目标值显著更高，启发式定价随任务数带来约 2.1x-13.1x 加速。它为 LaCAM 吞吐量研究提供了把任务分配、时窗和无碰路径联合考虑的路线生成/滚动重规划思路。
- [2203.02475 - Cooperative Task and Motion Planning for Multi-Arm Assembly Systems](briefs/2203.02475.md)：该文提出多臂装配的层次化任务-运动规划：高层用含关键碰撞与动作时长的 MILP 分配/排序任务，低层用优先级 MAPF/rSIPP 生成无碰撞轨迹。实验在最多 23 个物体的多臂装配中数分钟内得到低 makespan 解，瓶颈主要是路标生成和碰撞标注。它可启发 LaCAM 吞吐优化：把局部冲突、持续时间和任务依赖前置为轻量约束，引导搜索优先尝试更高吞吐且更可行的协同调度。
- [2305.06436 - Multi-Robot Coordination and Layout Design for Automated Warehousing](briefs/2305.06436.md)：论文把自动仓库吞吐优化从改进 MAPF 求解器转向布局设计，用 MAP-Elites/DSAGE 搜索高吞吐且多样的货架/端点布局，并用 MILP 修复可行性。实验显示优化布局显著减少拥堵、提升吞吐，在部分设置中把 RHCR 可扩展机器人数量从少于 150 提到超过 300。它提示 LaCAM 吞吐优化可把地图结构、瓶颈与机器人密度作为与求解器同等重要的调参/评测变量。
- [2307.00663 - Solving Multi-Agent Target Assignment and Path Finding with a Single Constraint Tree](briefs/2307.00663.md)：提出 ITA-CBS，用单棵约束树在 CBS 搜索中增量重算 1-best 目标分配，避免多树重复解冲突和 K-best 分配开销。论文报告其保持最优性，并在 6334 个测试中 96.1% 快于 CBS-TA。它为 LaCAM 吞吐优化提供了把任务/停靠点选择与避碰搜索耦合、减少重复局部规划的依据。
- [2308.11234 - Traffic Flow Optimisation for Lifelong Multi-Agent Path Finding](briefs/2308.11234.md)：论文借鉴交通分配，把边/顶点流量转成拥堵成本，生成并在线细化 time-independent guide paths，用来引导 PIBT，也可作为 LaCAM* 的启发式。大规模实验（4 类地图、最多 1.2 万智能体）显示其在 lifelong MAPF 中提高吞吐并把最优密度峰值推后，在 one-shot 中也优于含 LaCAM/LNS 在内的基线；这为 LaCAM throughput 方向提供了以预期拥堵/流量塑形启发式、而非只追最短路的依据。
- [2310.18622 - Arbitrarily Scalable Environment Generators via Neural Cellular Automata](briefs/2310.18622.md)：该文用 QD 在小环境中训练 NCA 环境生成器，而不是直接搜索大地图，再把局部生成规则扩展到任意尺度并用 MILP 修复约束。实验报告其生成环境在小规模上与既有 DSAGE 方法相当或更好，在最高约 2350 个机器人的大规模多机器人域中显著优于人工设计环境。它支撑 LaCAM 吞吐思路：把地图布局作为影响拥堵、行程距离和压力场景的可生成变量来优化与评测。
- [2311.14145 - Multi-Agent Motion Planning with Bézier Curve Optimization under Kinodynamic Constraints](briefs/2311.14145.md)：提出 PSB（三层 PBS-SIPP-Bézier），用优先级搜索解冲突、安全区间搜索给候选路径，再用 Bézier 曲线优化满足运动学约束的平滑速度轨迹。实验在路口协调和障碍栅格导航中相较既有方法最多降低 49.79% 代价/延误，并把栅格场景规模扩展到 220 个智能体。它为 LaCAM throughput 提供了离散搜索外接连续时间可行性、缓存复用与窗口化评估的依据。
- [2401.00315 - Bidirectional Temporal Plan Graph: Enabling Switchable Passing Orders for More Efficient Multi-Agent Path Finding Plan Execution](briefs/2401.00315.md)：BTPG把TPG中部分固定冲突点通过顺序改成可切换的双向依赖，执行时让机器人在安全条件下按先到先过减少等待。论文在3900个延迟仿真中报告BTPG相对TPG持续更快，减少约8-20%不必要等待。它为LaCAM吞吐优化提供依据：局部冲突处理可保留必要安全依赖、放松非必要顺序，让通道和瓶颈按实时到达状态释放。
- [2401.17044 - Scalable Mechanism Design for Multi-Agent Path Finding](briefs/2401.17044.md)：论文把机制设计引入自利代理的 MAPF，通过 maximal-in-range 约束搜索空间，并结合 VCG 支付构造 PCBS、EPBS 和 MCPP 等策略防护机制。实验在数十到数千代理的 MAPF 基准上显示，MCPP 相比搜索式机制更可扩展，并在 FCFS 基线之上提升社会福利。它为 LaCAM 吞吐优化提供了“固定候选范围/优先级采样中择优”的依据，可把可扩展规划与吞吐/福利目标连接起来。
- [2402.01446 - IJCAI-24 Formatting Instructions](briefs/2402.01446.md)：这不是有效的 MAPF 论文，而是 IJCAI-24 投稿格式说明模板。它不包含多智能体路径规划算法或吞吐量实验，不应作为吞吐量思路依据。
- [2403.18145 - A Real-Time Rescheduling Algorithm for Multi-robot Plan Execution](briefs/2403.18145.md)：论文针对多机器人执行中代理延迟造成的连锁等待，基于可切换 TPG 用 A* 风格的 SES 在线重排冲突位置的通过顺序，在保持安全约束下最小化到达时间。作者证明 SES 最优，实验中图式变体 GSES 在中小规模平均不到 1 秒求得最优 TPG，大规模最高比基线快 4 倍。它为 LaCAM 吞吐量优化提供了局部改写优先关系、快速吸收执行扰动而不全局重规划的机制参考。
- [2403.20300 - Improving Learnt Local MAPF Policies with Heuristic Search](briefs/2403.20300.md)：这篇论文把学习到的一步 MAPF 局部策略接入 PIBT/LaCAM，用完整动作概率分布重排行动与生成配置，以启发式搜索化解碰撞、死锁并支持全时域规划。实验报告成功率和可扩展性显著提升，并展示 ML-based MAPF 可扩展到 20% 智能体密度的高拥堵场景。它为 LaCAM 吞吐优化提供依据：用策略信号、随机采样和候选配置排序提高通过率，同时保留 LaCAM 的完整性搜索框架。
- [2404.00143 - Accelerating Search-Based Planning for Multi-Robot Manipulation by Leveraging Online-Generated Experiences](briefs/2404.00143.md)：论文用在线生成的路径经验加速 CBS/ECBS 式多机械臂规划，复用重复低层搜索以减少碰撞检查和重规划开销。实验中 xECBS 在最多 10 个机械臂任务上保持有界次优，并取得更高成功率与更低规划时间。它为 LaCAM 吞吐量优化提供依据：把已探索路径和约束搜索经验转化为后续实例的增量加速信号。
- [2404.05223 - ITA-ECBS: A Bounded-Suboptimal Algorithm for the Combined Target-Assignment and Path-Finding Problem](briefs/2404.05223.md)：ITA-ECBS 将 ITA-CBS 的单约束树目标分配框架改造成有界次优 TAPF 求解器，用焦点搜索和下界矩阵选择目标，避免直接套 ECBS 失去界限。实验中在 54,033 个至少一方求解的测试中 87.42% 快于 ECBS-TA，且成功率更高。它为 LaCAM 吞吐优化提供了把任务分配下界、单树冲突展开与有界次优搜索结合起来减少重规划开销的依据。
- [2404.16162 - Scaling Lifelong Multi-Agent Path Finding to More Realistic Settings: Research Challenges and Opportunities](briefs/2404.16162.md)：这篇论文把 lifelong MAPF 放到 1 秒/步、最多 1 万 agent、最高 97.7% 密度等真实吞吐压力下，核心机制是窗口化规划、PIBT 初解、并行 LNS 改进、历史计划复用，以及 guidance graph/禁用 agent 缓解拥堵。其方案在 LRR 竞赛 10 个隐藏实例中 9 个接近满分，总分 9.755 高于第二名 9.502，并赢得 Overall Best 与 Fast Mover。对 LaCAM 吞吐研究，它提示可把 LaCAM 放进滚动窗口、anytime/并行预算和交通引导框架中，从单次求解质量转向长期到达率与拥堵控制。
- [2405.01772 - Unconstraining Multi-Robot Manipulation: Enabling Arbitrary Constraints in ECBS with Bounded Sub-Optimality](briefs/2405.01772.md)：提出 Generalized ECBS，在 CBS/ECBS 中接纳任意（含不完整）约束，并用懒 CT 扩展、多 FOCAL 队列和动态约束优先级保持完备性与有界次优性。M-RAMP 实验显示它相较 ECBS、PP 等基线取得更高成功率，并显著改善规划时间与成功率。对 LaCAM 吞吐的启发是把激进局部约束作为可调度的冲突剪枝/重规划动作，在保持保障的同时优先使用高收益约束提升通过量。
- [2405.17794 - LNS2+RL: Combining Multi-Agent Reinforcement Learning with Large Neighborhood Search in Multi-Agent Path Finding](briefs/2405.17794.md)：LNS2+RL 在 LNS2 的迭代大邻域修复中，先用 MARL 为固定小邻域生成更少冲突的重规划路径，再切回 PP+SIPPS 快速清理残余冲突。论文报告其在高密度任务上整体优于 LNS2、LaCAM、EECBS、SCRIMP，复杂障碍地图中成功率优势尤其明显。它为 LaCAM 吞吐提升提供了局部高质量修复、拥堵热点重规划和求解器自适应切换的依据。
- [2407.09451 - Reevaluation of Large Neighborhood Search for MAPF: Findings and Opportunities](briefs/2407.09451.md)：论文统一重评 MAPF-LNS，核心是用破坏-修复式局部重规划选择高收益邻域，并用 RandomWalkProb 按延迟比例优先抽取高延迟智能体。实验显示规则启发式不弱于现有学习式选择，RandomWalk/RandomWalkProb 在多场景中鲁棒且常获最低最终延迟。它为 LaCAM 吞吐优化提供了基于高延迟/拥堵智能体的局部修复、邻域大小与重规划顺序调度依据。
- [2409.06888 - QD-MAPPER: A Quality Diversity Framework to Automatically Evaluate Multi-Agent Path Finding Algorithms in Diverse Maps](briefs/2409.06888.md)：QD-MAPPER 用质量多样性搜索优化 NCA 地图生成器，并用 MAPF 求解运行时间、成功率和地图模式指标自动构造多样压力测试。实验在 6 种代表算法上发现标准基准未暴露的长走廊/窄入口失效，LaCAM3 虽号称解出 99% 基准也会在这些图上超时。它为 LaCAM 吞吐研究提供了可自动生成瓶颈拓扑、定位拥堵模式并比较调度策略的评测框架。
- [2409.14491 - Work Smarter Not Harder: Simple Imitation Learning with CS-PIBT Outperforms Large Scale Imitation Learning for MAPF](briefs/2409.14491.md)：论文发现单靠大规模模仿学习不够，关键是把局部策略输出交给 CS-PIBT，用优先级继承与回溯解决一步碰撞。实验中仅 1 个场景、约 4 分钟训练即可达到当时 ML-MAPF SOTA，显著优于 EPH，并接近/受 PIBT 与 EECBS 表现约束。它为 LaCAM 吞吐优化提供依据：先用高效局部碰撞屏蔽释放密集流量，再把全局搜索/学习资源投入更长时域的目标冲突和瓶颈调度。
- [2410.01798 - Windowed MAPF with Completeness Guarantees](briefs/2410.01798.md)：WinC-MAPF 用实时启发式更新、启发式惩罚和不相交 agent 分组，让窗口化 MAPF 在短视规划下仍有完备性，SS-CBS 甚至只规划一步。论文报告 SS-CBS 在标准基准和高拥塞小图上比窗口 CBS 成功率更高，可避开死锁/活锁或全局 CBS 超时的场景。它为 LaCAM 吞吐提供依据：高密度短窗口重规划需要累积式拥塞/进展信号和分组独立性，才能稳定提升执行流量。
- [2410.03072 - Multi-Robot Motion Planning with Diffusion Models](briefs/2410.03072.md)：MMD 将单机器人扩散轨迹模型与约束式 MAPF 搜索结合，在去噪中加入时空碰撞约束，并可组合多个模型处理长时域和大地图。论文在物流风格仿真中展示可为数十台机器人生成符合数据分布的无碰轨迹，相比替代方案扩展性更好。它为 LaCAM 吞吐量提供启发：用快速离散协调作骨架，再用学习到的连续运动提升可执行性和拥堵通过效率。
- [2410.21415 - Deploying Ten Thousand Robots: Scalable Imitation Learning for Lifelong Multi-Agent Path Finding](briefs/2410.21415.md)：SILLM 用可扩展搜索求解器做模仿学习，并结合空间敏感通信、全局启发引导和 CS-PIBT 单步避碰来求解 lifelong MAPF。论文报告在 6 个大图、最多 10,000 个智能体上，相比学习/搜索基线平均吞吐分别提升 137.7%/16.0%，且每步规划低于 1 秒。它为 LaCAM 吞吐优化提供了把快速局部决策、拥堵感知引导和安全冲突修复结合起来的依据。
- [2411.16506 - Online Guidance Graph Optimization for Lifelong Multi-Agent Path Finding](briefs/2411.16506.md)：论文把静态 guidance graph 扩展为在线引导策略，用实时交通观测动态更新边权，并通过 CMA-ES 优化后接入 PIBT/GPIBT。实验显示在静态和动态任务分布下，相比离线引导吞吐最高提升 30.75%，相比人工在线引导最高提升 52.42%。这为 LaCAM 吞吐优化提供了可落地的思路：把局部拥堵反馈转化为可在线调整的边权/通道偏好，指导搜索避开热点。
- [2412.13359 - Multi-Agent Motion Planning For Differential Drive Robots Through Stationary State Search](briefs/2412.13359.md)：MASS 将 MAPF 冲突处理、SSIPP 静止状态搜索和速度曲线求解组成三层框架，把差速机器人零速旋转与速度/加速度约束纳入规划。论文报告在单次与 lifelong 仓储仿真中提升成功率和吞吐，摘要称吞吐最高提升 400%。这为 LaCAM throughput 提供了思路：吞吐优化应同时关注离散冲突、执行时间、停转点和局部运动可行性。
- [2412.15908 - Speedup Techniques for Switchable Temporal Plan Graph Optimization](briefs/2412.15908.md)：本文把 MAPF 执行延迟下的访问顺序建模为可切换时序计划图（STPG），用 Improved GSES 通过更强可采纳启发、边分组、优先分支和增量最长路更新来快速确定无死锁无碰撞的优先约束。实验显示 IGSES 在多数场景至少将成功率翻倍，并在共同可解实例上较 GSES 提速 10-30 倍、节点扩展减少 90% 以上。对 LaCAM 吞吐量优化，它提供了将局部让行/等待顺序作为可切换约束并用增量图代价评估来降低拥堵等待的依据。
- [2503.02992 - RAILGUN: A Unified Convolutional Policy for Multi-Agent Path Finding Across Different Environments and Tasks](briefs/2503.02992.md)：RAILGUN 将 MAPF 动作从 agent 级改为地图栅格级预测，用 U-Net 为每个格点输出下一步方向，从而形成每步一个专用有向图。论文报告其在 POGEMA 上优于多数学习基线，并在未见地图、agent 数和 LMAPF 上有较强零样本泛化，但吞吐/SoC 质量仍落后于 LaCAM。它为 LaCAM 吞吐量优化提供了可学习的地图级候选方向、拥堵先验和任务目标微调思路。
