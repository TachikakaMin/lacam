# Work Smarter Not Harder: Simple Imitation Learning with CS-PIBT Outperforms Large Scale Imitation Learning for MAPF

简短介绍：论文发现单靠大规模模仿学习不够，关键是把局部策略输出交给 CS-PIBT，用优先级继承与回溯解决一步碰撞。实验中仅 1 个场景、约 4 分钟训练即可达到当时 ML-MAPF SOTA，显著优于 EPH，并接近/受 PIBT 与 EECBS 表现约束。它为 LaCAM 吞吐优化提供依据：先用高效局部碰撞屏蔽释放密集流量，再把全局搜索/学习资源投入更长时域的目标冲突和瓶颈调度。
