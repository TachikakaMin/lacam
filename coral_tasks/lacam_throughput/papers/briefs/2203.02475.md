# Cooperative Task and Motion Planning for Multi-Arm Assembly Systems

简短介绍：该文提出多臂装配的层次化任务-运动规划：高层用含关键碰撞与动作时长的 MILP 分配/排序任务，低层用优先级 MAPF/rSIPP 生成无碰撞轨迹。实验在最多 23 个物体的多臂装配中数分钟内得到低 makespan 解，瓶颈主要是路标生成和碰撞标注。它可启发 LaCAM 吞吐优化：把局部冲突、持续时间和任务依赖前置为轻量约束，引导搜索优先尝试更高吞吐且更可行的协同调度。
