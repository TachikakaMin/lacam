# Planning over MAPF Agent Dependencies via Multi-Dependency PIBT

简短介绍：本文把 PIBT 的优先级继承视为在智能体依赖图上搜索，提出 MD-PIBT，用硬/软依赖、w 步候选路径和回溯重规划处理多智能体同时冲突。实验显示它可规划最多 10,000 个同质智能体，并在大体积智能体 MAPF 中显著优于 PIBT/EPIBT，但在普通 one-shot/lifelong 设置多为追平。它为 LaCAM 吞吐优化提供了“把密集互挡显式建成可搜索依赖子图”的依据，可用于提升局部冲突解除与窗口化推进。
