# Pathfinding with Lazy Successor Generation

简短介绍：本文提出 LaCAS* 的惰性后继生成：不一次性枚举所有邻居，而随搜索推进用 k-d tree/k 近邻逐步展开。实验显示它能在传统方法失效的复杂实例上更快找到解，并保持完备、anytime 且最终收敛最优。对 LaCAM 吞吐可借鉴为按需生成候选移动，减少无效连通/冲突检查，把预算集中到更可能提升吞吐的扩展上。
