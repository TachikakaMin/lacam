# winPIBT: Extended Prioritized Algorithm for Iterative Multi-agent Path Finding

简短介绍：winPIBT 将 PIBT 的单步优先级继承扩展为可配置时间窗口，让智能体沿短路径预留多个时空节点并把优先级传递给阻塞者以局部消解冲突。论文证明在与 PIBT 类似的图条件下可达，并报告合适窗口能缓解 PIBT 的活锁、通常生成更高效路径。它为 LaCAM 吞吐量改进提供了窗口化前瞻、动态优先级和局部让路协同的依据。
