# Graph Attention-Guided Search for Dense Multi-Agent Pathfinding

简短介绍：LaGAT 将图注意力神经策略 MAGAT+ 作为轻量启发式嵌入 LaCAM，用预训练+地图微调给 PIBT/LaCAM 的下一步选择提供学习偏好，并用碰撞屏蔽和死锁检测兜底。论文报告其在高密 MAPF 中优于纯搜索和纯学习方法，虽有神经推理开销，但解质量提升足以抵消开销并在稠密场景超过 lacam3 的实时表现。对 LaCAM throughput，可借鉴为候选排序、优先级/局部动作偏好和拥堵死锁检测提供学习信号，在保持 LaCAM 可恢复搜索框架下提高有效扩展率。
