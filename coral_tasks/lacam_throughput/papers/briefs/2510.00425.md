# Conflict-Based Search as a Protocol: A Multi-Agent Motion Planning Protocol for Heterogeneous Agents, Solvers, and Independent Tasks

简短介绍：这篇论文把 CBS 抽象为只要求单体 plan() 接口的多机器人协议，由中央层检测冲突并下发时空约束给异构求解器重规划。实验显示它能组合 A*/RRT/优化/扩散/RL 等求解器处理独立任务，非零根冲突实例成功率为 54%，经验复用可显著降低查询时间。它为 LaCAM throughput 提供了“冲突定位、约束注入、局部重算、经验复用”的机制参照，提示吞吐瓶颈应重点看低层查询速度和冲突检查成本。
