# Solving Multi-Agent Target Assignment and Path Finding with a Single Constraint Tree

简短介绍：提出 ITA-CBS，用单棵约束树在 CBS 搜索中增量重算 1-best 目标分配，避免多树重复解冲突和 K-best 分配开销。论文报告其保持最优性，并在 6334 个测试中 96.1% 快于 CBS-TA。它为 LaCAM 吞吐优化提供了把任务/停靠点选择与避碰搜索耦合、减少重复局部规划的依据。
