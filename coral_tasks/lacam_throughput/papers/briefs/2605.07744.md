# Alternating Target-Path Planning for Scalable Multi-Agent Coordination

简短介绍：论文提出交替目标-路径规划的 TAPF 框架，将目标分配与路径规划解耦，用 LaCAM/LaCAM3 快速求解当前分配并按路径反馈重分配瓶颈智能体。实验中 DBS-Hungarian 相比 ITA-ECBS 保持 100% 成功率并扩展到 800 智能体，规模测试还覆盖到 10,000 智能体。这为 LaCAM 吞吐优化提供了依据：用快速 MAPF 评估拥堵与延迟，再反馈驱动任务分配和瓶颈缓解。
