# Distance-Constrained Unlabeled Multi-Agent Pathfinding

简短介绍：这篇论文把 unlabeled MAPF 扩展为距离 r 独立约束，并用 IU-PIBT 生成下一配置，再由 IU-LaCAM 结合搜索和活锁检测摆脱卡死。结果显示该问题虽变为 PSPACE-complete，但仍可在实用时间内处理数百个智能体。对 LaCAM throughput 可借鉴其“局部快速推进 + 搜索修正”机制，把距离/可达性约束前置为任务分配过滤和安全吞吐裕量。
