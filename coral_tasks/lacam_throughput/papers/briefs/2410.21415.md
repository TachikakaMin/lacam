# Deploying Ten Thousand Robots: Scalable Imitation Learning for Lifelong Multi-Agent Path Finding

简短介绍：SILLM 用可扩展搜索求解器做模仿学习，并结合空间敏感通信、全局启发引导和 CS-PIBT 单步避碰来求解 lifelong MAPF。论文报告在 6 个大图、最多 10,000 个智能体上，相比学习/搜索基线平均吞吐分别提升 137.7%/16.0%，且每步规划低于 1 秒。它为 LaCAM 吞吐优化提供了把快速局部决策、拥堵感知引导和安全冲突修复结合起来的依据。
