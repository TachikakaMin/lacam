# Online Guidance Graph Optimization for Lifelong Multi-Agent Path Finding

简短介绍：论文把静态 guidance graph 扩展为在线引导策略，用实时交通观测动态更新边权，并通过 CMA-ES 优化后接入 PIBT/GPIBT。实验显示在静态和动态任务分布下，相比离线引导吞吐最高提升 30.75%，相比人工在线引导最高提升 52.42%。这为 LaCAM 吞吐优化提供了可落地的思路：把局部拥堵反馈转化为可在线调整的边权/通道偏好，指导搜索避开热点。
