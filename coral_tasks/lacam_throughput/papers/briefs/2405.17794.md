# LNS2+RL: Combining Multi-Agent Reinforcement Learning with Large Neighborhood Search in Multi-Agent Path Finding

简短介绍：LNS2+RL 在 LNS2 的迭代大邻域修复中，先用 MARL 为固定小邻域生成更少冲突的重规划路径，再切回 PP+SIPPS 快速清理残余冲突。论文报告其在高密度任务上整体优于 LNS2、LaCAM、EECBS、SCRIMP，复杂障碍地图中成功率优势尤其明显。它为 LaCAM 吞吐提升提供了局部高质量修复、拥堵热点重规划和求解器自适应切换的依据。
