# RAILGUN: A Unified Convolutional Policy for Multi-Agent Path Finding Across Different Environments and Tasks

简短介绍：RAILGUN 将 MAPF 动作从 agent 级改为地图栅格级预测，用 U-Net 为每个格点输出下一步方向，从而形成每步一个专用有向图。论文报告其在 POGEMA 上优于多数学习基线，并在未见地图、agent 数和 LMAPF 上有较强零样本泛化，但吞吐/SoC 质量仍落后于 LaCAM。它为 LaCAM 吞吐量优化提供了可学习的地图级候选方向、拥堵先验和任务目标微调思路。
