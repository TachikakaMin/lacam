# Destination-to-Chutes Task Mapping Optimization for Multi-Robot Coordination in Robotic Sorting Systems

简短介绍：该文提出机器人分拣系统中的目的地到滑槽任务映射优化，用仿真显式耦合映射、目标分配、PIBT 路径协调与滑槽关闭状态，并以 EA 搜索、MILP 修复合法映射。实验显示优化映射在不同布局、滑槽数和目的地设置中相对贪心基线提升吞吐并降低回流率，QD 分析进一步揭示靠近工作站与同目的地聚集之间的布局相关权衡。它为 LaCAM 吞吐研究提供了将任务/站点映射、容量关闭和交通拥堵作为上游分布设计变量来评测 MAPF 协调器的依据。
