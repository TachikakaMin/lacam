# Conveyor Parcel Routing with Order-Contiguous Arrivals

简短介绍：论文将输送线包裹路由建模为带“同订单连续到达”约束的在线 MAPF，提出 DOPP：先排订单块顺序，再细化包裹优先级并用优先规划生成无碰撞路径。实验显示 DOPP 在真实仓库式网络上能紧预算内可扩展重规划，千级可见智能体仍接近亚秒级，并在在线场景显著压低 makespan。它启发 LaCAM 吞吐优化把局部避碰扩展为批次/订单级优先结构、窗口重规划与瓶颈利用率驱动的搜索。
