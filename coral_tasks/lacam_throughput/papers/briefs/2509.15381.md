# Dynamic Agent Grouping ECBS: Scaling Windowed Multi-Agent Path Finding with Completeness Guarantees

简短介绍：DAG-ECBS 将 WinC-MAPF 的启发式更新和不相交分组扩展到有界次优 ECBS，从单体组出发，对冲突/启发式冲突组迭代合并重规划，并保持每组 w-有界次优与完备性。实验显示它比 SS-CBS 更可扩展，在小窗口或拥堵图上也优于无完备保证的 windowed ECBS。它为 LaCAM 吞吐量优化提供了动态局部分组、窗口执行和启发式惩罚来缓解拥堵/死锁的依据。
