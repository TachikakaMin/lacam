# A Real-Time Rescheduling Algorithm for Multi-robot Plan Execution

简短介绍：论文针对多机器人执行中代理延迟造成的连锁等待，基于可切换 TPG 用 A* 风格的 SES 在线重排冲突位置的通过顺序，在保持安全约束下最小化到达时间。作者证明 SES 最优，实验中图式变体 GSES 在中小规模平均不到 1 秒求得最优 TPG，大规模最高比基线快 4 倍。它为 LaCAM 吞吐量优化提供了局部改写优先关系、快速吸收执行扰动而不全局重规划的机制参考。
