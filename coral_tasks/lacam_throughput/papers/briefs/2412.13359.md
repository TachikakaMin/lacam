# Multi-Agent Motion Planning For Differential Drive Robots Through Stationary State Search

简短介绍：MASS 将 MAPF 冲突处理、SSIPP 静止状态搜索和速度曲线求解组成三层框架，把差速机器人零速旋转与速度/加速度约束纳入规划。论文报告在单次与 lifelong 仓储仿真中提升成功率和吞吐，摘要称吞吐最高提升 400%。这为 LaCAM throughput 提供了思路：吞吐优化应同时关注离散冲突、执行时间、停转点和局部运动可行性。
