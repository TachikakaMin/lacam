# Local Guidance for Configuration-Based Multi-Agent Pathfinding

简短介绍：本文为 LaCAM 引入局部指导，在每个配置附近用窗口化的个体路径和时空拥堵线索重排 PIBT/配置生成器的移动偏好。实验报告其在 1000 个智能体规模下通常仍能数秒响应，极端案例相对原始 LaCAM 将解成本降低 50%，且多数优于全局指导和 anytime 基线。这直接支撑 LaCAM 吞吐优化思路：把局部拥堵与等待代价转成动态偏好信号，减少密集场景中的停等和瓶颈。
