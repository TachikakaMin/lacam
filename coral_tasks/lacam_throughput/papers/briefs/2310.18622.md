# Arbitrarily Scalable Environment Generators via Neural Cellular Automata

简短介绍：该文用 QD 在小环境中训练 NCA 环境生成器，而不是直接搜索大地图，再把局部生成规则扩展到任意尺度并用 MILP 修复约束。实验报告其生成环境在小规模上与既有 DSAGE 方法相当或更好，在最高约 2350 个机器人的大规模多机器人域中显著优于人工设计环境。它支撑 LaCAM 吞吐思路：把地图布局作为影响拥堵、行程距离和压力场景的可生成变量来优化与评测。
