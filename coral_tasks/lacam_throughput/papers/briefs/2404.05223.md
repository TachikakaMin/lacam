# ITA-ECBS: A Bounded-Suboptimal Algorithm for the Combined Target-Assignment and Path-Finding Problem

简短介绍：ITA-ECBS 将 ITA-CBS 的单约束树目标分配框架改造成有界次优 TAPF 求解器，用焦点搜索和下界矩阵选择目标，避免直接套 ECBS 失去界限。实验中在 54,033 个至少一方求解的测试中 87.42% 快于 ECBS-TA，且成功率更高。它为 LaCAM 吞吐优化提供了把任务分配下界、单树冲突展开与有界次优搜索结合起来减少重规划开销的依据。
