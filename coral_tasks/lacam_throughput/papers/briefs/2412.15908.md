# Speedup Techniques for Switchable Temporal Plan Graph Optimization

简短介绍：本文把 MAPF 执行延迟下的访问顺序建模为可切换时序计划图（STPG），用 Improved GSES 通过更强可采纳启发、边分组、优先分支和增量最长路更新来快速确定无死锁无碰撞的优先约束。实验显示 IGSES 在多数场景至少将成功率翻倍，并在共同可解实例上较 GSES 提速 10-30 倍、节点扩展减少 90% 以上。对 LaCAM 吞吐量优化，它提供了将局部让行/等待顺序作为可切换约束并用增量图代价评估来降低拥堵等待的依据。
