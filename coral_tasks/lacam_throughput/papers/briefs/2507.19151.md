# ReCoDe: Reinforcement Learning-based Dynamic Constraint Design for Multi-Agent Coordination

简短介绍：ReCoDe 保留优化控制器与安全约束，用 MARL/GNN 学习随场景变化的附加约束，动态调整每个体的可行动作集以缓解拥堵和死锁。论文报告在四个多智能体导航/共识任务中平均比次优方法高 18% 奖励，并在窄走廊实机换位中让原本死锁的控制器成功通过。对 LaCAM throughput，它支持把学习到的局部拥堵、让行和候选收缩机制用于优先级与扩展排序，在保持搜索骨架可靠性的同时提升吞吐。
