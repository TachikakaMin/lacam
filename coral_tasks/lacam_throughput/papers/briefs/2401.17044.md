# Scalable Mechanism Design for Multi-Agent Path Finding

简短介绍：论文把机制设计引入自利代理的 MAPF，通过 maximal-in-range 约束搜索空间，并结合 VCG 支付构造 PCBS、EPBS 和 MCPP 等策略防护机制。实验在数十到数千代理的 MAPF 基准上显示，MCPP 相比搜索式机制更可扩展，并在 FCFS 基线之上提升社会福利。它为 LaCAM 吞吐优化提供了“固定候选范围/优先级采样中择优”的依据，可把可扩展规划与吞吐/福利目标连接起来。
