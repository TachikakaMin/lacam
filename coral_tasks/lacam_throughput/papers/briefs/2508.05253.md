# Congestion Mitigation Path Planning for Large-Scale Multi-Agent Navigation in Dense Environments

简短介绍：CMPP 将密集多智能体导航抽象为稀疏图，用入边流量的乘性拥堵代价生成粗粒度、时间无关的引导路线，促使流量同向或分散以避开交叉瓶颈。实验中，CMPP+ORCA 将 400 智能体连续导航成功率从 83.9% 提升到 99.0%，CMPP+PIBT 在 1,500 智能体 lifelong-MAPF 仓库中最高提升 58% 吞吐。它为 LaCAM 吞吐优化提供全局拥堵代价、热点分流和粗路线引导思路，可作为局部搜索之外的流量整形信号。
