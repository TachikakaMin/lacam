# Polynomial-time Configuration Generator for Connected Unlabeled Multi-Agent Pathfinding

简短介绍：论文提出 PULL，用规则式一步配置生成在 CUMAPF 中保持连通、避免冲突并向目标推进。实验中它在 500 个体时平均 makespan/LB 不到朴素方案的 0.3 倍，并可接入 LaCAM* 最终收敛到最优。对 LaCAM 吞吐优化而言，它具体化了“快速合法后继生成器 + 搜索逐步改进”的路线，可借鉴为低成本候选配置生成与约束保持机制。
