# WinkTPG: An Execution Framework for Multi-Agent Path Finding Using Temporal Reasoning

简短介绍：WinkTPG 将离散 MAPF 计划转成 TPG/kTPG 上的动力学可行速度剖面，用预留时间区间、安全裕量和窗口重规划处理共享位置次序与执行不确定性。论文报告可在 1 秒内为 1000 个智能体生成速度剖面，并相对既有执行方法最高提升 51.7% 解质量。它为 LaCAM 吞吐优化提供执行层依据：把路径输出进一步转成可在线更新的时间预留与速度调度，减少保守等待并权衡鲁棒性和效率。
