# Scalable Algorithms with Provable Optimality Bounds for the Multiple Watchman Route Problem

简短介绍：本文研究多看守人路径问题，通过可视性支配剪枝、状态空间压缩和更快更强的启发式，将覆盖路径搜索从联合空间中减负。实验报告在复杂地图上搜索空间减少超过95%，最优规划比基线快200倍以上，次优有界算法可扩展到1500+栅格和5+智能体。对LaCAM吞吐量优化的启发是：用可证明的剪枝、启发式重排和有界次优搜索减少无效扩展，把多智能体覆盖/服务任务转化为更高吞吐的分解调度。
