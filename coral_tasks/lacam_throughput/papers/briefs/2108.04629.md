# Roadside-assisted Cooperative Planning using Future Path Sharing for Autonomous Driving

简短介绍：论文提出车辆周期共享未来路径，RSU 用预约表检测冲突或加速机会，并下发协调路径调节速度。在盲交叉口两车仿真中，RSU 协同将平均通过时间从 36.51s 降至 27.05s，报告 23.0% 改善。它为 LaCAM 吞吐优化提供了“提前共享意图、预约冲突资源、局部重规划排序”的机制依据。
