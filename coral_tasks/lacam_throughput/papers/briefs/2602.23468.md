# Optimization of Edge Directions and Weights for Mixed Guidance Graphs in Lifelong Multi-Agent Path Finding

简短介绍：论文把 GGO 扩展为混合引导图优化（MGGO），同时优化边方向和边权；边方向提供硬约束，ERS 通过反转边保持强连通，QD/两阶段方法生成方向与权重。实验中提出方法整体优于基线并刷新 LMAPF 引导图 SOTA，在 PIBT 上各设置总有一种方法取得最高吞吐，边方向尤其能减少旋转动作。它为 LaCAM 吞吐提升提供了可落地线索：把局部搜索的通行偏好、单向通道和拥堵代价做成可学习/可优化的图级引导。
