# Bidirectional Temporal Plan Graph: Enabling Switchable Passing Orders for More Efficient Multi-Agent Path Finding Plan Execution

简短介绍：BTPG把TPG中部分固定冲突点通过顺序改成可切换的双向依赖，执行时让机器人在安全条件下按先到先过减少等待。论文在3900个延迟仿真中报告BTPG相对TPG持续更快，减少约8-20%不必要等待。它为LaCAM吞吐优化提供依据：局部冲突处理可保留必要安全依赖、放松非必要顺序，让通道和瓶颈按实时到达状态释放。
