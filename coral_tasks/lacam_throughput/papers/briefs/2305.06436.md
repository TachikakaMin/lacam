# Multi-Robot Coordination and Layout Design for Automated Warehousing

简短介绍：论文把自动仓库吞吐优化从改进 MAPF 求解器转向布局设计，用 MAP-Elites/DSAGE 搜索高吞吐且多样的货架/端点布局，并用 MILP 修复可行性。实验显示优化布局显著减少拥堵、提升吞吐，在部分设置中把 RHCR 可扩展机器人数量从少于 150 提到超过 300。它提示 LaCAM 吞吐优化可把地图结构、瓶颈与机器人密度作为与求解器同等重要的调参/评测变量。
