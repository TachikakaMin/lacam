# Traffic Flow Optimisation for Lifelong Multi-Agent Path Finding

简短介绍：论文借鉴交通分配，把边/顶点流量转成拥堵成本，生成并在线细化 time-independent guide paths，用来引导 PIBT，也可作为 LaCAM* 的启发式。大规模实验（4 类地图、最多 1.2 万智能体）显示其在 lifelong MAPF 中提高吞吐并把最优密度峰值推后，在 one-shot 中也优于含 LaCAM/LNS 在内的基线；这为 LaCAM throughput 方向提供了以预期拥堵/流量塑形启发式、而非只追最短路的依据。
