# Improving Learnt Local MAPF Policies with Heuristic Search

简短介绍：这篇论文把学习到的一步 MAPF 局部策略接入 PIBT/LaCAM，用完整动作概率分布重排行动与生成配置，以启发式搜索化解碰撞、死锁并支持全时域规划。实验报告成功率和可扩展性显著提升，并展示 ML-based MAPF 可扩展到 20% 智能体密度的高拥堵场景。它为 LaCAM 吞吐优化提供依据：用策略信号、随机采样和候选配置排序提高通过率，同时保留 LaCAM 的完整性搜索框架。
