# D4orm: Multi-Robot Trajectories with Dynamics-aware Diffusion Denoised Deformations

简短介绍：D4orm把多机器人联合控制轨迹看作可迭代去噪的变形，用动力学 rollout 与适应度函数经蒙特卡洛近似引导扩散式优化，无需训练数据。实验在2D/3D、差速/全向团队上生成动力学可行且无碰撞轨迹，16个2D全向机器人约2秒完成、接近比MPPI/CEM快2倍，并零样本部署到8架多旋翼。对LaCAM吞吐量研究，它提示可把离散路径输出接上并行 rollout、奖励塑形和anytime平滑/去冲突层，以提升执行可行性和高密度流量。
