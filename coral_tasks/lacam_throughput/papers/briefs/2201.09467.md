# CTRMs: Learning to Construct Cooperative Timed Roadmaps for Multi-agent Path Planning in Continuous Spaces

简短介绍：CTRMs 用 CVAE 从 MAPP 示范中学习协作的时空采样，为每个智能体构造带时间的专属 roadmap，让 MAPF 在更小的高潜力空间中搜索。实验在 21–40 个智能体、障碍和异构设置下，将节点展开/运行时间等规划 effort 降低数个数量级，同时保持相近成功率与解质量。对 LaCAM throughput 的启发是用离线经验压缩并排序候选扩展，把协作与时间信息前置以减少无效展开。
