# Offline Time-Independent Multi-Agent Path Planning

简短介绍：OTIMAPP 将多智能体路径规划从精确时刻表转为无时序假设的路径集合，要求任意公平异步执行下都不会永久互堵并最终到达目标。论文给出死锁判定、PP/DBS 求解器，实验显示可计算一定规模实例，在时序不利环境中仍保持机器人移动效率并可落到实体机器人。对 LaCAM 吞吐优化的启发是，把“避免会导致阻塞的路径/任务组合”作为调度约束，减少运行时同步、重规划和拥堵放大。
