# QD-MAPPER: A Quality Diversity Framework to Automatically Evaluate Multi-Agent Path Finding Algorithms in Diverse Maps

简短介绍：QD-MAPPER 用质量多样性搜索优化 NCA 地图生成器，并用 MAPF 求解运行时间、成功率和地图模式指标自动构造多样压力测试。实验在 6 种代表算法上发现标准基准未暴露的长走廊/窄入口失效，LaCAM3 虽号称解出 99% 基准也会在这些图上超时。它为 LaCAM 吞吐研究提供了可自动生成瓶颈拓扑、定位拥堵模式并比较调度策略的评测框架。
