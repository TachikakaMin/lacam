# Iterative Refinement for Real-Time Multi-Robot Path Planning

简短介绍：提出面向实时 MAPF 的 anytime 迭代精化框架：先用次优求解器快速给出可行路径，再反复选取部分机器人用最优求解器局部重规划、固定其余路径。实验显示它在小实例中很快接近最优，在大规模场景仍保持响应性和可接受成本。它为 LaCAM 吞吐优化提供依据：用快速可行解承接在线节拍，再在有限时预算内做局部邻域改进来提升滚动调度质量。
