# Accelerating Focal Search in Multi-Agent Path Finding with Tighter Lower Bounds

简短介绍：DECBS 针对 ECBS 低层 focal search 的 LB 增长慢问题，先求受约束最短路代价作为最大 LB，再在界内按冲突数选择候选。论文报告其可减少近 30% 高层 CT 节点和 50% 低层 focal 节点，高密度场景相对 ECBS 平均提速 23.5%。这为 LaCAM 吞吐优化提供依据：用更紧成本界扩大/裁剪候选，再用冲突或拥堵信号重排局部推进。
