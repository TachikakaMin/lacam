# Multi-Robot Routing with Time Windows: A Column Generation Approach

简短介绍：将仓库多机器人拣选建模为带时间窗、容量和避碰约束的加权集合打包，列生成只生成有价值的机器人路线，并把定价化为 ERCSPP。实验报告完整 CG 相比改造的 CG+MAPF 目标值显著更高，启发式定价随任务数带来约 2.1x-13.1x 加速。它为 LaCAM 吞吐量研究提供了把任务分配、时窗和无碰路径联合考虑的路线生成/滚动重规划思路。
