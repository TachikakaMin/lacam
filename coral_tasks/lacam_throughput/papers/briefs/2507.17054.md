# New Mechanisms in Flex Distribution for Bounded Suboptimal Multi-Agent Path Finding

简短介绍：论文改进 EECBS 的 flex distribution，将次优界内的松弛量按冲突数量和约束带来的延迟估计分配，并用混合策略控制总代价不越界。实验显示 CFD/DFD 超过原 EECBS 与贪心 GFD，MFD 在 120 秒时限内进一步提升成功率。它为 LaCAM 吞吐优化提供了“把等待/绕行预算投向拥堵与高延迟局部”的机制依据。
