# Windowed MAPF with Completeness Guarantees

简短介绍：WinC-MAPF 用实时启发式更新、启发式惩罚和不相交 agent 分组，让窗口化 MAPF 在短视规划下仍有完备性，SS-CBS 甚至只规划一步。论文报告 SS-CBS 在标准基准和高拥塞小图上比窗口 CBS 成功率更高，可避开死锁/活锁或全局 CBS 超时的场景。它为 LaCAM 吞吐提供依据：高密度短窗口重规划需要累积式拥塞/进展信号和分组独立性，才能稳定提升执行流量。
