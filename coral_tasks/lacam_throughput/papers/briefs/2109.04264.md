# Solving Simultaneous Target Assignment and Path Planning Efficiently with Time-Independent Execution

简短介绍：TSWAP 面向无标签 MAPF，把目标分配和路径规划动态耦合：先给任意初始分配，再按单步路径推进，并在冲突/阻塞时交换目标。论文报告其在大规模离线实例上能快速得到近 makespan 最优解，运行时间较最优流方法低数个数量级，在线版本还具备延迟容忍。对 LaCAM 吞吐量的启发是，将 pickup/drop 选择视为可随搜索和拥堵状态重绑定的目标，使任务分配、路径代价和局部瓶颈联动。
