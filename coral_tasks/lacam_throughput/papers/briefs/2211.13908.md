# Fault-Tolerant Offline Multi-Agent Path Planning

简短介绍：该文提出 MAPPCF：机器人运行中可能崩溃并永久占据节点，正确机器人依靠局部故障检测在预备路径与切换规则间切换。DCRF 逐个处理崩溃影响并生成备份路径，实验显示比顶点完全不相交路径能覆盖更多实例且无故障时成本更低。它为 LaCAM 吞吐量研究提供了故障后局部修补、快速恢复、减少全局停顿的依据。
