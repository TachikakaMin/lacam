# LaCAM: Search-Based Algorithm for Quick Multi-Agent Pathfinding

简短介绍：LaCAM 用高层搜索全体配置序列、低层惰性增量生成约束来减少扩展开销。论文报告其在多类 MAPF 场景中成功率、规划时间和 sum-of-costs 质量可比或优于主流次优算法，并能快速处理数百智能体。它为 LaCAM throughput 提供依据：优化惰性约束生成、配置扩展顺序和低层调用成本。
