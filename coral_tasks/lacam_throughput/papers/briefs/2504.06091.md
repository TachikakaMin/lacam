# Real-Time LaCAM for Real-Time MAPF

简短介绍：Real-Time LaCAM 将一次性全局 LaCAM DFS 改为跨迭代保留历史的增量搜索，每轮在毫秒级预算内继续扩展、执行下一步，并用重根与重访约束避免死锁/活锁。实验显示它在不同毫秒级 cutoff 下与 full-horizon LaCAM 保持相同成功率和近似总规划时间，但极小 cutoff 会牺牲路径质量。它可为 LaCAM throughput 提供渐进式思路：先产出可执行动作，再复用搜索树、约束和局部策略持续改善拥塞场景吞吐。
